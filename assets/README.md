Profile artwork uses original Minecraft-inspired pixel glyphs drawn as SVG shapes and a forest / matcha palette inspired by https://omarchy.org. The lettering renders consistently without font files, viewer-installed fonts, JavaScript, or an image host. It is an original pixel alphabet, not the official Minecraft font. GitHub controls the font of the README’s regular Markdown text, code blocks, and third-party badges and stats cards.

Run `python3 scripts/render-profile.py` from the repository root to regenerate the terminal banner, footer, four navigation cards, and three section headings. Their CSS animations respect reduced-motion preferences; meaningful text also appears in the README and image descriptions.

`matcha-snake.svg` begins as an explicitly labeled welcome panel. `.github/workflows/snake.yml` replaces it with real public contribution data on its first run, then daily. Push the workflow to `main` or run **Tend the contribution garden** from GitHub Actions. The workflow needs Actions enabled and permission to push to `main`; branch protection may require an adjustment. Only the generated snake file is committed. Its animation is generated by Platane/snk and is independent of the banners' motion settings.

The visitor badge retains its original provider, username, and URL. The optional stats cards still depend on the existing GitHub Readme Stats service. `profile-3d-contrib.yml` remains an inactive root-level file.
